{{- if and .Values.services.api.enabled (not (include "tankovault.redisUrl" .)) }}

NOTE: no Redis is configured. The API rate limiter falls back to per-replica in-memory counters,
which multiplies every configured limit by the replica count, and SSE tickets become
process-local. Set `valkey.enabled=true` or `externalRedis.url`.
{{- end }}

Configuration reloads in place. Every service watches its mounted config and secret directories
and rebuilds its runtime when the kubelet refreshes them, so `helm upgrade` with a changed
`config` value does NOT restart pods — expect the change to take effect within a kubelet sync
period (~1 minute), with the restart count unchanged. The exceptions are `telemetry.*` and
`metrics.*`, which are installed process-globally and need a real restart:

  kubectl --namespace {{ include "common.namespace" . }} rollout restart deployment \
    --selector app.kubernetes.io/part-of={{ include "common.name" . }}

Legal documents supplied through `legal.documents.<slug>.content` are the same story: the API
re-reads them behind an mtime check, so correcting a policy is a `helm upgrade` and a kubelet
sync, not a restart.
